FAQ

Cara pakai

Panduan lengkap dari membuka builder sampai file APK selesai dibuat. Manusia sudah cukup dipusingkan oleh Android, jadi alurnya dibuat lurus.

1. Bagaimana membuat APK dari website?
Pilih tab Build, biarkan mode Web (URL), isi Nama aplikasi, Nama paket, lalu masukkan alamat website lengkap seperti https://contoh.com.
2. Bagaimana membuat APK dari file HTML?
Pada area Build, pilih HTML (Upload). Setelah itu pilih file .html atau .htm. File tersebut akan dikirim sebagai sumber aplikasi ke proses build.
3. Apa fungsi nama paket?
Nama paket menjadi identitas paket Android. Gunakan format seperti com.nama.aplikasi, dengan bagian-bagian dipisahkan titik.
4. Ikon aplikasi dan splash untuk apa?
Ikon aplikasi menentukan gambar ikon APK. Pada bagian Splash, pilih Default, Gambar, HTML, atau Video sesuai aset yang ingin dipakai, kemudian unggah file saat opsi tersebut meminta file.
5. Apa fungsi orientasi layar?
Otomatis mengikuti pengaturan default builder, sedangkan Potret dan Lanskap memaksa orientasi yang dipilih.
6. Versi dan kode versi harus diisi?
Keduanya bersifat opsional pada form ini. Nama versi dan Kode versi hanya dikirim ketika diisi.
7. Setelah klik Bangun APK, apa yang terjadi?
Builder mengirim data form ke layanan build. Ketika berhasil, halaman menampilkan nama file dan tombol Unduh APK. Saat gagal atau koneksi bermasalah, pesan error akan muncul di area status.
8. Drawer sebelah kiri untuk apa?
Drawer berisi shortcut navigasi dan menu Donasi. Tekan tombol menu untuk membuka. Klik tombol menu lagi, tombol tutup, item menu, atau area di luar drawer untuk menutupnya.
PEMBERITAHUAN

Untuk pengguna Luk2APK

Website ini dikembangkan dengan waktu, tenaga, dan perhatian agar tetap bisa digunakan dengan nyaman. Di balik setiap fitur ada biaya server, layanan, pengembangan, dan pemeliharaan yang perlu terus berjalan.

Dukungan dari pengguna sangat berarti.

Jika Luk2APK membantu pekerjaan atau project kamu, dukungan kepada pengembang bisa menjadi tanda apresiasi yang tulus. Dukungan tersebut membantu menjaga pengembangan dan pemeliharaan website ini tetap berjalan.

Fitur dukungan/donasi saat ini ditutup sementara karena kendala keamanan pada QRIS. Jangan melakukan pembayaran melalui QRIS lama atau gambar QRIS yang beredar atas nama Luk2APK. Tidak ada kewajiban untuk memberikan dukungan.

PRIVACY POLICY

Kebijakan Privasi Luk2APK

Kebijakan ini menjelaskan secara sederhana bagaimana Luk2APK menangani informasi ketika kamu menggunakan website Web & HTML to APK Builder.

1. Informasi yang diproses
Luk2APK memproses data yang kamu masukkan sendiri ke dalam builder, seperti nama aplikasi, nama paket, alamat website, pilihan orientasi, versi aplikasi, serta file yang kamu pilih untuk proses pembuatan APK. Data tersebut diperlukan agar permintaan build dapat dikirim ke layanan yang menjalankan proses pembuatan APK.
2. File yang kamu unggah
File HTML, ikon, gambar splash, atau video splash hanya digunakan sebagai bagian dari konfigurasi build yang kamu kirim. Jangan mengunggah dokumen pribadi, kata sandi, token rahasia, data identitas, atau file lain yang tidak diperlukan. Project yang disimpan melalui fitur Project Manager disimpan di penyimpanan browser perangkat untuk membantu kamu melanjutkan konfigurasi. Aset file tidak otomatis disalin ke project tersimpan.
3. Penyimpanan lokal
Beberapa data seperti project dan riwayat build dapat disimpan menggunakan localStorage pada browser. Penyimpanan ini berada di perangkat dan browser yang kamu gunakan. Menghapus data situs, membersihkan penyimpanan browser, atau menggunakan perangkat/browser berbeda dapat membuat data lokal tersebut tidak tersedia lagi.
4. Layanan pihak ketiga
Luk2APK menggunakan layanan pihak ketiga untuk kebutuhan tertentu, termasuk layanan build APK, pemuatan font, hosting gambar, dan hosting video. Ketika browser atau builder berkomunikasi dengan layanan tersebut, informasi teknis yang diperlukan oleh layanan terkait dapat ikut diproses sesuai kebijakan masing-masing penyedia. Luk2APK tidak mengklaim mengendalikan kebijakan privasi pihak ketiga tersebut.
5. API build dan alamat website
Saat kamu memilih mode Web (URL), alamat website yang kamu masukkan dapat dikirim ke layanan build sebagai bagian dari permintaan pembuatan APK. Pastikan kamu memiliki hak untuk membungkus website tersebut menjadi aplikasi dan jangan memasukkan URL yang berisi informasi rahasia.
6. Keamanan
Luk2APK berupaya menggunakan komunikasi HTTPS dan membatasi data yang diperlukan untuk fungsi builder. Namun, tidak ada layanan internet yang dapat menjamin keamanan mutlak. Kamu bertanggung jawab untuk tidak mengirim rahasia, kredensial, API key pribadi, atau data sensitif melalui kolom dan file yang tidak ditujukan untuk itu.
7. QRIS dan dukungan pengembang
Fitur QRIS sedang ditutup sementara karena kendala keamanan. QRIS sebelumnya dilaporkan telah dicuri atau disalin oleh pihak ketiga dari aplikasi. Karena itu, Luk2APK tidak meminta pengguna melakukan pembayaran melalui QRIS lama, gambar QRIS yang beredar, atau sumber yang tidak ditampilkan melalui fitur resmi yang sedang aktif. Sampai fitur dibuka kembali secara resmi, jangan menganggap QRIS lama sebagai sarana pembayaran Luk2APK.
8. Notifikasi dan interaksi
Notifikasi welcome yang muncul saat halaman dibuka adalah elemen antarmuka lokal. Luk2APK tidak menggunakan notifikasi tersebut untuk meminta kata sandi atau informasi pembayaran. Jika terdapat pesan yang meminta data sensitif atas nama Luk2APK, periksa sumbernya sebelum memberikan informasi.
9. Hak dan pilihan pengguna
Kamu dapat berhenti menggunakan website kapan saja dan dapat menghapus data project atau riwayat yang tersimpan secara lokal melalui fitur yang tersedia atau melalui pengaturan penyimpanan browser. Untuk data yang diproses oleh layanan pihak ketiga, permintaan penghapusan atau akses mengikuti kemampuan dan kebijakan penyedia layanan tersebut.
10. Perubahan kebijakan
Kebijakan ini dapat diperbarui ketika fitur, layanan, atau cara kerja Luk2APK berubah. Versi terbaru yang ditampilkan pada website menjadi acuan untuk penggunaan setelah perubahan tersebut. Perubahan penting akan dijelaskan secara wajar melalui bagian pemberitahuan atau antarmuka terkait.
Catatan privasi

Gunakan Luk2APK hanya untuk data yang memang diperlukan oleh proses build. Untuk keamanan, jangan mengunggah rahasia atau data pribadi yang tidak diperlukan. Kebijakan ini menjelaskan praktik website berdasarkan fitur yang tersedia saat ini, bukan jaminan bahwa semua layanan pihak ketiga memiliki praktik yang sama.
